# RealmDom — Forest Realm prototype

A playable web prototype of RealmDom, a location-based team game where your real streets become a fantasy map.

- Play: https://eladhefetz.github.io/realms/
- Choose **Use my real streets** and allow location access to play on your own neighborhood (map data © OpenStreetMap contributors).
- Other players are simulated by AI in this prototype.
